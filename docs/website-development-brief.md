# Grape Pro — Website Development Brief

## 1. Project Overview

Build an alternative website for **Grape**, an online professional networking initiative.

- Brand: Grape
- Website: grape.place
- Tagline: Meet . Connect . Grow
- GitHub repository: grape-place/grape-pro
- Design direction: Warm Editorial Minimalism
- Purpose: A professional-looking alternative to Grape's existing colourful, playful website
- Status: Design prototype for co-founder review, not approved for production launch

The website should feel sophisticated, welcoming, credible, contemporary and minimalist.

Avoid an overly corporate appearance. Avoid playful illustrations, confetti, ribbons, decorative squiggles and unnecessary animation.

The intended audience includes founders, business owners, employees, independent professionals and anyone interested in meaningful professional networking.

## 2. Technical Requirements

- React with Vite
- Tailwind CSS
- Fully responsive, mobile-first design
- Reusable components
- Accessible semantic HTML
- Clean, maintainable code
- Optimised images and typography
- No backend or database
- No login or signup functionality
- No changes to the existing Grape V1 repository or deployment
- Netlify-compatible production build

## 3. Visual Design System

**Direction 01 — Warm Editorial Minimalism**

Colour palette:

- Warm cream: `#F7F5F0`
- Charcoal: `#252326`
- Deep grape purple: `#48205F`
- Soft lavender: `#DDD6E4`

These are starting colours, not an absolute restriction. Refine the shades to match the supplied reference mockup.

Typography:

- Elegant, expressive serif typography for major headlines
- Clean, contemporary sans-serif for navigation, descriptions, event details and buttons
- Strong hierarchy and generous whitespace
- Large, readable hero typography
- Avoid excessive boldness and visual clutter

Design characteristics:

- Spacious editorial layouts
- Restrained purple accents
- Subtle borders and dividers
- Gentle rounded corners
- Minimal use of shadows
- Clear content hierarchy
- Professional but warm

Use the supplied full-page mockup as the primary visual reference. Do not invent an entirely new design direction.

## 4. Header and Navigation

Use the supplied Grape logo.

Navigation:

- How it works
- Upcoming sessions
- Your Hosts
- Contact

No login, signup or user account controls.

Contact should use the existing Tally form popup when the configuration is available.

## 5. Hero Section

The hero must be **text-only**.

No AI-generated photography, people, laptops or illustrations.

Primary headline:

**Meet. Connect. Grow.**

Supporting text:

A series of online networking sessions that brings professionals together for meaningful, focused conversations.

Additional description:

Expand your network, exchange ideas and discover new opportunities — in a relaxed, engaging online setting.

Primary CTA:

**Explore upcoming sessions**

The hero should be the strongest visual section of the website, relying on typography, composition, whitespace and subtle colour treatments.

## 6. Upcoming Sessions

Create an elegant, scannable list of upcoming 2027 events.

Use the existing Grape event schedule and themes as the source of truth.

The latest visual concept contains these provisional themes:

- Startups & Entrepreneurship
- AI in Work and Business
- Career Transitions & Redundancy
- The Future of Healthcare
- Cross-Industry Connections I
- Cross-Industry Connections II

Do not treat these themes, dates or times as final unless confirmed by the existing project content.

Each event should show:

- Theme
- Date or TBA
- Time and timezone, if confirmed
- Online format
- Registration link or a non-clickable Coming Soon status

Do not invent registration URLs or imply that registrations are open.

## 7. How Grape Works

Present three simple steps:

**Register**

Choose one of our upcoming online networking sessions.

**Connect**

Meet other professionals in small breakout rooms and enjoy meaningful conversations.

**Rotate**

Move into new breakout rooms and meet more people.

Use simple icons, restrained dividers and an elegant horizontal desktop layout that stacks naturally on mobile.

## 10. Footer

Include:

- Grape branding
- Meet . Connect . Grow
- Navigation links
- Contact
- LinkedIn as the only social platform

Do not add Instagram, Facebook, YouTube or other social icons.

## 11. Responsive Behaviour

Desktop:

- Spacious layouts
- Wide editorial hero
- Clearly structured event listings
- Side-by-side host profiles

Tablet:

- Adapt columns and spacing naturally

Mobile:

- Compact navigation
- Readable headline wrapping
- Event cards or stacked event rows
- Vertically stacked host profiles
- No horizontal scrolling
- Comfortable tap targets

## 12. Important Development Instructions

Before coding:

1. Inspect the repository and existing files.
2. Identify the supplied reference mockup, logo and founder photographs.
3. Identify missing assets and any unconfirmed content.
4. Propose the component structure and implementation plan.
5. Report any questions or blockers.

Do not begin implementation until the plan has been reviewed.

Once approved, build the complete homepage in a coherent first iteration rather than creating unrelated placeholder sections.

The goal is a visually polished, realistic website prototype suitable for co-founder review.
